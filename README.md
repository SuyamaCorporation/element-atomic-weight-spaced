# 元素・原子量スペースドリビュー

周期表全118元素の記号・名称・原子量をスペースドリピティション方式で学習できるアプリ。正解後に電子配置・発見年・用途を表示する解説カード付き。

## 機能
- 全118元素を収録（記号・日本語名・原子量・電子配置・発見年・主用途）
- 軽元素（Z1–20）・遷移金属（Z21–56）・希土類・重元素（Z57–118）のグループフィルター
- 元素記号→名前 / 名前→元素記号の2種クイズモード
- 4択クイズ形式、正解後に詳細解説カードを表示
- 簡易SM-2スペースドリピティションで習得済みは出題頻度を低減
- グループ別習得率プログレスバー
- localStorageに学習進捗を保存
